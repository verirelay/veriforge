# VeriForge

VeriForge 是 VeriRelay 启动产物集的可复现构建工具：任何人都能从公开源码重新构建出逐字节相同的产物，把启动度量对回源码。

VeriForge is the reproducible builder for the VeriRelay Boot Artifact Set: anyone can rebuild byte-for-byte identical artifacts from public source and tie the Launch Measurement back to it.
